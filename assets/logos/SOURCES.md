# Institution Logos

These marks identify the authors' affiliations. They remain the property of
their respective owners and are not covered by this repository's code license.
Tencent and Samsung are parent-organization marks, not separate lab logos.

The README displays the colored marks on a white background in
`institutions.png`, rendered at 3x resolution with unchanged proportions.
The same colored banner is used for both GitHub themes. Original SVG paths and
the individual light/dark assets are retained here. The updated banner pairs
the official Tsinghua and Zhejiang seal-and-name lockups, using the same layout
as the project page. No school-name lettering is typeset separately.
The Tsinghua lockup comes from https://www.tsinghua.edu.cn/image/logo.png;
its white silhouette is rendered in university purple for the banner.
